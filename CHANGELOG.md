- EN: The client learns a new role right after vanilla `/op` and `/deop`: the wheel and the Server window show the Operator ring and the staff tabs by the new role. Before, the role came only on login, so a de-opped player saw them until relogging (the server still rejected the actions). RYSCore 1.17.3.

- EN: `/rys admin journal` shows the action in words, like the Server window: "Dev created kit check1123" instead of "Dev kit_create check1123". Every journal entry type has a verb in both languages (checked by a test); an unknown type is shown as words.

## 0.2.9 (23.11.2026)

Остатки русского текста в коде убраны: к публикации на CurseForge интерфейс полностью английский.

- Правила сервера по умолчанию на двух языках. На новом сервере с русским языком системы в `config/ryshelm/rules.md` ложатся прежние русские правила, на любом другом английские. Готовый файл правил не меняется.
- Журнал персонала на языке читателя. Новая запись хранит рядом с прежней русской строкой ключи, окно «Сервер» и `/rys admin journal` собирают её на языке оператора: сроки, «только смотрел», состояние жалобы, изменения настроек. Старые записи читаются и показываются как были. «Консоль» и «сервер» в журнале и истории наказаний тоже переводятся.
- В списке банов игры у бана из консоли источник «Server».
- Отчёт шага переезда `admin` (`/rys migrate`) по ключам `ryshelm.migrate.*`, в отчёт по-английски, как лог и файл переезда ядра. Подпись перенесённого заглушения на языке системы сервера.
- Ошибка разбора лестницы в настройках показывает введённую строку на любом языке.
- Логи сервера и тексты исключений по-английски. Неиспользуемые русские подписи логики (`Term.label`, `Kind.noun`, `Ladder.Step.label`, `KitRule.label`) убраны, слова даёт `Lang`.
- Ядро 1.17.1 внутри jar: подписи мыши и клавиш и ответы `/rys migrate` на языке игры.
- Тесты: английские правила по умолчанию, журнал ключами (запись, чтение, старые записи), ключи из `Said.of` есть в файлах перевода.

### English

The last hardcoded Russian text is gone: the whole interface is ready in English.

- Default server rules come in two languages. A new server on a Russian system gets the Russian rules in `config/ryshelm/rules.md`, any other gets English ones. An existing rules file is never touched.
- The staff journal follows the reader's language. New entries keep translation keys next to the Russian line on disk, so the Server window and `/rys admin journal` show them in the operator's language. Old entries read as before.
- Bans from the console show "Server" as the source in the game's ban list.
- The `admin` migration step (`/rys migrate`) reports in English, like the core's migration log and report file.
- Server logs and exception messages are in English.
- Bundled RYSCore 1.17.1: mouse and key labels and `/rys migrate` replies follow the game language.

## 0.2.8 (23.11.2026)

Окно «Сервер» и сообщения мода на двух языках.

- Весь текст игроку идёт через файлы перевода `ru_ru.json` и `en_us.json`: вкладки, кнопки, подсказки, окно наказания, правила при входе, колесо, уведомления, ответы команд `/rys admin …`, `/report`, `/sc`, экраны бана и выгона. Русский текст прежний, английский новый. Склонения как в семье (`.one`, `.few`, `.many`).
- Сервер пишет игроку на языке, который тот выбрал в игре. Клиент без мода видит готовый текст на своём языке, а не ключ перевода (экраны отключения, чат персонала и заголовки сундуков идут `translatableWithFallback`). Консоль получает английский.
- Журнал персонала и логи сервера на диске не менялись. Окно показывает строки журнала на языке игрока; в русском «включил белый список» вместо «включён белый список».
- В файлах перевода не хватало короткого имени «Корзина» (RU) и «Return» (EN) для колеса, добавлены.
- Тест `LangFilesTest`: ключи двух файлов совпадают, у склоняемых ключей все формы, подстановки сходятся, в коде окна нет русских строк, каждый ключ из кода есть в файлах, русские сроки слово в слово прежние.

### English

The Server window and all mod messages now come in Russian and English.

- Every player-facing line goes through `ru_ru.json` and `en_us.json`: tabs, buttons, hints, the punishment dialog, rules on join, the action wheel, notices, replies to `/rys admin …`, `/report`, `/sc`, ban and kick screens.
- The server answers each player in the language they picked in the game. A client without the mod still sees readable text in its language, never a raw key. The console gets English.
- The staff journal and server logs on disk are unchanged; the window shows journal lines in the viewer's language.

## 0.2.4 (черновик, 19.11.2026)

Отзыв автора о вкладке «Настройки» 19.11 («или лагает, или идёт обновление на сервер, нужны лоадеры на кнопках», «не всё ровно сидит»). Ядро 1.15.3.

- Причина задержки: после правки окно ждало общей рассылки сервера раз в секунду и до неё показывало старое значение. Быстрые нажатия «+» считались от старого значения и давали один шаг на серию, двойной клик по переключателю ничего не менял, а «Сохранить» на мгновение возвращал в поле старый текст и оставлял его.
- Теперь правка видна сразу (`ui.Pending` ядра): переключатель, счётчик, флажок, выбор набора и срок журнала показывают новое значение, через 150 мс без ответа кнопка, переключатель и счётчик рисуют крутилку, снимаемый ник или модератор тускнеет с крутилкой вместо крестика. Сервер отвечает на каждое такое действие (пакет `ack` с номером запроса) и сразу присылает свежую вкладку, не дожидаясь рассылки. Ошибка (её текст приходит уведомлением) или молчание дольше 6 с возвращают значение сервера, на молчание уведомление «Сервер не ответил». Слишком частые действия получают отказ, а не тишину. Старый сервер без ответов: окно шлёт как раньше.
- Поля «Приветствие», «Имя сервера», «Лестница»: присланное сервером значение ложится в поле, только если его не правят; при ошибке набранный текст остаётся. «Добавить» в белом списке чистит поле только после успеха.
- Шапка: вкладки встают сразу за именем сервера, имя берёт столько места, сколько оставляют вкладки (до 130), обрезанное имя показывает подсказку. Раньше имя резалось до 40 и всё равно наезжало на «Игроки», потому что вкладки стояли на постоянном месте.
- Поиск в шапке как в окне карты: лупа всегда слева, текст и подсказка начинаются после неё, справа место под плашку «/». Раньше поле начиналось от края, и лупа лежала поверх подсказки.
- Плашки ников белого списка и модераторов: крестик по середине плашки (`Ui.chipCross`), поле ника на ровном отступе. Переключатели в рядах по середине двух строк. Врезки и «Наборы» в правой колонке встают друг под другом по своей высоте, без постоянных мест и дыры.
- Автотест `ui`: вкладка «Настройки» (снимки `helm_15_settings`, `helm_15_settings_busy`), ответ сервера на антиспам, два «+» до ответа, откат непонятой лестницы, снятие мест без ответа через 6 с.

## 0.2.3 (черновик, 19.11.2026)

Ночные проверки 19.11 (`_shared/_audit/night-tests-2026-11-19.md`, ошибки 1 и 2). Ядро 1.15.1.

- Правила при входе: модераторы и операторы не ждут принятия правил. Оператор, включивший правила, больше не остаётся без чата и действий до их принятия; окно правил само персоналу не открывается, прочитать и принять можно `/rys rules`.
- Лестница наказаний: наказание со сроком (заглушить, бан) считается, только пока действует. Истёкший бан в счёт не идёт: у игрока с предупреждением 3 дня назад и истёкшим баном следующий шаг «заглушить на 1 ч», как в макете 09. Предупреждения и «выгнать» считаются в окне 30 дней, как раньше.
- JUnit: истёкший бан и действующее наказание вне окна. Сценарий `duo` проверяет, что Alpha после включения правил не ждёт их принятия.

## 0.2.0 (черновик, 19.11.2026)

## 0.1.0 (черновик, 19.11.2026)

Первая версия, этапы А1–А4 плана Essentials. Ядро RYSCore 1.14.0.

- Роли оператор, модератор, игрок через `perm.Roles` ядра; таблица прав `perm.Perms` для узлов всех модов семьи; 23 узла `ryshelm.*`.
- Наказания: предупреждение, заглушить, выгнать, бан со сроком в списке игры. Потолки модератора: заглушить до 1 дня, бан до 7 дней, навсегда только оператор. Лестница наказаний с подсказкой в окне.
- Журнал персонала по месяцам со сроком хранения.
- Окно «Сервер»: игроки, карточка игрока, окно наказания, правила, жалобы, журнал, роли, настройки. Кнопка в панели семьи, действия колеса ядра.
- Жалобы с местом, землёй и строками чата; уведомления модераторам и автору.
- Правила при входе, новичок, чат персонала, заморозка, наблюдение.
- Инвентарь и сундук Края игрока («только смотреть» модератору), корзина, `/kickme`, команды оператора.
- Шаг переезда `admin`: муты и место «где видели» из FTB Essentials. Пока FTB Essentials стоит, его команды не заняты, шаг не идёт.
